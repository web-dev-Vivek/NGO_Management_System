# Unity NGO Volunteer Management System — Product Documentation

This package contains the product, UX, design, AI chatbot, trust, SEO, and roadmap documentation for the Unity NGO Volunteer Management System.

## Technology
- React 19 + Vite
- React Router
- Clerk
- Node.js + Express
- MongoDB + Mongoose
- Multer
- PDFKit

## Roles
Admin, Coordinator, Volunteer

## Main Product Flow
Authentication → Profile → Campaign → Registration → Task → Check-in/out → Verification → Certificate → Analytics

## AI Extension
The system includes a planned organization-data chatbot using permission-aware retrieval and optional RAG for uploaded documents.
