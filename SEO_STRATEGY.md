# SEO Strategy

## Public SEO Pages

- Active campaigns
- About the organization
- Public certificate verification

## Metadata
Each public page should define:
- title
- description
- canonical URL
- Open Graph metadata

## Technical SEO
- Semantic HTML
- Accessible headings
- Fast page loading
- Mobile responsiveness
- Descriptive URLs
- Sitemap and robots configuration where applicable
