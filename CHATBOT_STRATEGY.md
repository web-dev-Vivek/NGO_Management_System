# Chatbot Strategy

## Phase 1
Answer from structured NGO records:
- campaigns
- tasks
- volunteers
- hours
- certificates

## Phase 2
Add organization documents and policies.

## Phase 3
Add semantic search/RAG for uploaded documents.

## Phase 4
Add analytics questions and role-aware summaries.

## Non-Goals
The chatbot should not make administrative changes unless explicit, authenticated action tools are later introduced.
