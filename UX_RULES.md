# UX Rules

1. Never expose actions that the current role cannot perform.
2. Protected pages must redirect unauthenticated users.
3. Show loading states for asynchronous operations.
4. Show explicit success/error feedback after mutations.
5. Use confirmation before blocking users, deleting data, or issuing irreversible actions.
6. Keep campaign registration one or two actions maximum.
7. Check-in and check-out controls must clearly show the current task state.
8. Verified hours must be visually distinguishable from unverified hours.
9. Certificate verification should require only the certificate code.
10. Tables should support search/filtering where datasets can grow large.
