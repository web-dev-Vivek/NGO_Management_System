# Page Structure

## Landing
Hero → mission/value proposition → features → impact statistics → CTA.

## Dashboard
Role-specific summary cards → recent activity → pending actions → charts where applicable.

## Campaign Explorer
Filters → campaign cards → campaign detail → registration.

## Tasks
Task list → task detail → priority/deadline → check-in/check-out → logged hours.

## Certificates
Certificate list → certificate preview → verification code → download.

## User Directory
Search → role/status filters → user table → role/status actions.

## Public Verification
Certificate code input → verification result → certificate metadata.
