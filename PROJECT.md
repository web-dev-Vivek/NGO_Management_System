# Unity NGO Volunteer Management System

## Project Purpose
A full-stack NGO volunteer management platform connecting Admins, Coordinators, and Volunteers.

## Core Modules
- Authentication and profiles
- Campaign management
- Volunteer registration
- Task assignment and hours tracking
- Certificate generation and public verification
- Analytics and administration
- Role-Based Access Control (RBAC)

## Roles
### Admin
Full system control: user approval/blocking, coordinator approval, campaign publishing, certificates, and analytics.

### Coordinator
Creates campaign proposals, assigns tasks, and verifies volunteer hours.

### Volunteer
Explores campaigns, registers, completes assigned tasks, logs hours, and accesses certificates.
