# Design System

## Style
Use a dark, professional dashboard aesthetic with glassmorphism.

## Layout
- Persistent sidebar on desktop
- Collapsible navigation where appropriate
- Topbar with user/session controls
- Responsive content area
- Cards and tables for operational data

## UI Principles
- Role-specific actions should be obvious.
- Destructive actions require confirmation.
- Status should always be represented by text and visual badges.
- Empty states should explain the next action.
- Forms should provide validation feedback.
